# The Last Torch

A third-person temple-escape game made in **Unity 6 (URP)** for the *Fundamentals of Game Development* lab
(scenario: "The Forgotten Temple"). Every asset (textures, meshes, sounds, materials, prefabs, scenes and UI)
is **generated by C# code**. The project uses no external asset packs.

> *The map led you here. The door slammed shut behind you.*
> *Your torch won't last forever.*
> *Find the Heart of Eternity, and find a way out.*

## Download and play

1. Open the **[Releases](../../releases)** page and download `TheLastTorch-Windows.zip`.
2. Unzip it anywhere and run **`TheLastTorch.exe`** (Windows 64-bit).

## Objective

You are trapped in a pitch-dark temple maze. Your torch is your light, your timer and your vision.

1. Find the **3 symbol keys**: Sun, Moon and Serpent.
2. Door **A** opens with the Sun Key and leads to the Trap Gallery.
3. Place all three keys in the **Inner Sanctum** door (press **E**).
4. Take the **Heart of Eternity**. The temple starts to collapse.
5. Reach the **exit gate** before the countdown ends.

**You lose if** your torch runs out of fuel, you lose all your hearts, or the collapse timer reaches 0.

## Controls

| Key | Action |
|---|---|
| WASD / Arrow keys | Move |
| Mouse | Look around (third-person camera) |
| Shift | Sprint (burns fuel faster) |
| E | Interact (place keys in the Sanctum door) |
| M | Big map (the corner map is always shown) |
| Esc | Pause menu |

## Scoring

| Action | Points |
|---|---|
| Gem | +10 |
| Oil jar (also +25 fuel) | +5 |
| Key | +50 |
| Heart of Eternity | +200 |
| Taking damage | -20 per hit |
| Escape bonus (win only) | +5 per second left on the collapse timer |
| Torch bonus (win only) | +1 per unit of fuel left |

## Features

- **Torch fuel mechanic:** fuel drains constantly (faster when sprinting and on Hard), and the light radius
  shrinks as fuel drops. Oil jars refuel the torch.
- **Traps:** spike tiles that rise in a wave, dart plates that fire from the walls, and a rolling boulder.
- **Puzzle doors:** a key door, a three-socket Sanctum door, an entrance that slams shut behind you, and an
  exit gate that opens when the temple collapses.
- **Collapse sequence:** countdown, red screen effect, camera shake and falling rocks with warning circles.
- **HUD:** fuel bar, hearts, key icons, score, hints, floating points and a minimap with key markers.
- **Player profiles:** name entry, best score, wins and attempts, a top-5 leaderboard, and saved settings
  (all stored in PlayerPrefs).
- **Difficulty:** Easy / Normal / Hard (changes the fuel burn rate).
- **Procedural assets:** noise-based stone textures with normal maps, low-poly meshes, synthesized sound
  effects and music, and a character built from primitives with procedural animation.
- **Live tuning:** every gameplay number is in one `GameSettings` asset and can be changed during Play mode.

## Open the project in Unity

1. Install **Unity 6000.3.24f1** with Windows Build Support.
2. Clone this repository and open the folder in Unity Hub.
3. Unity opens the **MainMenu** scene. Press **Play**.
4. To regenerate everything from code: top menu **The Last Torch → Build All (1 + 2)**.
5. To build the game: **The Last Torch → 3. Build Windows EXE** (output: `Builds/Windows/`).

### Changing the game

- **Tunable values:** **The Last Torch → Select Game Settings**, then edit the fields. Values update
  instantly in Play mode.
- **Maze layout:** edit `maze.txt` (`#` wall, `.` floor, `S` start, `1 2 3` keys, `*` Heart, `X` exit,
  `^` spikes, `T` dart plate, `B`/`b` boulder) and run **The Last Torch → 2. Build Scenes**.

### Project structure

```
Assets/
  Scripts/   Core, Player, World, Traps, UI, Profile      (game code)
             Editor/Generators, Builders, Utilities        (asset and scene generators)
  Generated/ Textures, Meshes, Materials, Audio, Prefabs, PostFX   (created by the generators)
  Scenes/    MainMenu, Temple
  Settings/  GameSettings.asset, Rendering/
```
