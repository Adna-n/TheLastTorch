## 2. Technical Rules (Claude Code must follow)

1. **Namespace** `LastTorch` for runtime and `LastTorch.EditorTools` for editor scripts.
2. **Input:** Unity 6 projects use the **new Input System** by default. Read `ProjectSettings/ProjectSettings.asset` → `activeInputHandler`. Use `UnityEngine.InputSystem` device polling (`Keyboard.current`, `Mouse.current`). Don't use the old `Input.GetAxis`. The EventSystem must use `InputSystemUIInputModule`, not `StandaloneInputModule`.
3. **UI:** uGUI with legacy `UnityEngine.UI.Text` and the built-in font `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")`. That avoids the TextMeshPro essentials import. All UI is built by code in the SceneBuilder. Canvas Scaler: Scale With Screen Size, 1920×1080, match 0.5.
4. **Shaders:** never call `Shader.Find` at runtime, because shaders get stripped in builds. Create every material as an `.mat` asset in the editor using `Universal Render Pipeline/Lit`, `Universal Render Pipeline/Unlit` or `Universal Render Pipeline/Particles/Unlit`. For emission: `EnableKeyword("_EMISSION")`, set `_EmissionColor`, `globalIlluminationFlags = RealtimeEmissive`.
5. **Generated assets must be saved as assets.** Meshes go through `AssetDatabase.CreateAsset` (`.asset`), textures are written as PNG then re-imported with the right `TextureImporter` settings, audio as `.wav`, materials as `.mat`, prefabs through `PrefabUtility.SaveAsPrefabAsset`. Otherwise prefab references break.
6. **All generators are deterministic** (fixed random seed) and **idempotent**: running them twice overwrites cleanly.
7. **Tunables** live only in `GameSettings` (ScriptableObject at `Assets/Settings/GameSettings.asset`), referenced through `GameManager.Settings`. No magic numbers in gameplay scripts.
8. Every script starts with a 2–4 line summary comment.
9. Remove colliders from decorative primitive parts. Only the root objects that need collision keep them.
10. Scenes are generated: `Assets/Scenes/MainMenu.unity` and `Assets/Scenes/Temple.unity`, both added to Build Settings (MainMenu = index 0).

## 5. The Maze (`maze.txt`)

Each character = one cell (`cellSize` = 4 m). Row 0 = north. The level builder reads it from `Assets/Resources/maze.txt`, so I can edit the layout as text.

```
#########################
#O....#.....g#.2#B....b3#
#.###.#.###.##.########.#
#...#...#g#.....#g......#
###.#####.#####.#.#######
#g#.......#..O..#.^.^.^.#
#.#####.#.#.###.#######.#
#....#..#...#...#..TT.O.#
#.##.#.####.#.#.#.#######
#.#1.#....#...#.#.^^.^^.#
#.####.##.###.#.#######.#
#......#O.....#.#g.T.T..#
############.####.#######
#.........#.....#.......#
#.........#.g...#^.^.^.^#
X..*......H.....A.......#
#.........#..O..#..g....#
#.........#.....#.......#
############.############
#..O........S........g..#
############D############
```

| Char | Meaning |
|---|---|
| `#` | Stone wall block (wallHeight tall) |
| `.` | Floor |
| `S` | Player spawn |
| `D` | Entrance door: open at start, **slams shut** 1.5 s after spawn (camera shake + slam sound) |
| `O` | Oil jar (+fuel) |
| `g` | Gem (score) |
| `1` `2` `3` | Sun key · Moon key · Serpent key |
| `A` | Door that needs the **Sun key** (leads to the Trap Gallery) |
| `H` | **Sanctum door**: needs all 3 keys, 3 glowing sockets |
| `*` | Heart of Eternity on an altar |
| `X` | Exit gate: sealed until the Heart is taken, then opens. Walking through it = **WIN**. Place a bright "daylight" glow beyond it. |
| `^` | Spike trap tile (timed; neighbouring spikes are offset so they make a wave) |
| `T` | Dart pressure plate: fires darts across the corridor from both side walls |
| `B` | Boulder start · `b` boulder trigger tile (boulder rolls along the row toward the trigger and on to the wall) |

**Zones:** bottom row = Entrance Hall → middle hub → left-top = Labyrinth (Sun + Moon keys) → door A → right = Trap Gallery (Serpent key at the top, with the boulder on the way back) → hub → door H = Inner Sanctum (Heart) → gate X → outside.
*(Reachability has been checked: every tile is reachable once the right doors are open.)*

**Builder details:**
- Merge horizontal runs of `#` into single long wall blocks to keep the object count low. Use world-space UVs so the texture tiles evenly.
- Floor = one big plane per zone or one per row run. No ceiling: the camera background is solid black, so it reads as an enclosed dark temple.
- Random decoration (seeded): vines on ~15% of wall faces, faint emissive glyph panels on ~8% of wall faces, rubble piles in dead ends, broken pillars in the Sanctum corners.
- Collectibles glow faintly (emission) so they're findable in the dark.

## 6. Procedurally Generated Assets

### Textures (`TextureGenerator`, 512×512 PNG, layered Perlin/fBm noise)
| Texture | How |
|---|---|
| `stone_wall` (+ normal map) | Brick/block grid with noise-jittered mortar lines, fBm colour variation around `#4F5D50`/`#6E7867`, dark cracks |
| `stone_floor` (+ normal) | Large irregular flagstones (Voronoi cells), darker grout, sandy dirt patches |
| `moss` | Green `#1E3B2A`–`#3F7A44` blotches with alpha, for vines and wall overlays |
| `glyph_sun`, `glyph_moon`, `glyph_serpent` | Drawn with code (circles, rays, crescent, sine curve) as white on transparent, used as emissive maps |
| `glyph_random_1..4` | Random carved symbols for wall decoration |
| `clay` | Terracotta `#8A4A24` noise with ring bands, for the oil jars |
| `wood` | Stretched noise grain, for the torch handle and door frames |
| `soft_particle` | Radial soft circle, for fire, embers, dust |
| `ui_vignette`, `ui_bar` | Rounded bar sprites and a radial vignette for the HUD |

### Meshes (`MeshGenerator`)
Octahedron (gems), elongated crystal (Heart), pyramid/cone (spikes), cylinder with configurable segments (jar body, torch handle, pillars), jar (lathe/revolve profile mesh), low-poly rock (noise-displaced icosphere, for debris and the boulder), dart (thin cylinder + cone tip), altar (stacked boxes).

### Audio (`AudioGenerator`: 16-bit PCM mono 44.1 kHz WAV writer, all synthesized)
| Clip | Synthesis |
|---|---|
| `torch_loop` | Low-passed noise + random short crackle pops (seamless loop, 4 s) |
| `ambient_drone` | Layered low sines (55/82/110 Hz) with slow LFO, plus random water drips (loop, 20 s) |
| `footstep_1..4` | Short filtered noise thumps with pitch variation |
| `pickup_gem` | Quick rising sine arpeggio |
| `pickup_oil` | Low bubbly "glug" (FM sweep) |
| `pickup_key` | Bell chord (additive sines, exponential decay) |
| `door_grind` | Brown noise with slow pitch wobble, 2 s |
| `door_slam` | Low sine thump + noise burst + decay |
| `spike_up` | Short metallic click/scrape (high band-passed noise) |
| `dart_whoosh` | Band-pass noise sweep high→low |
| `boulder_roll` | Low rumble loop |
| `hurt` | Short descending square wave + noise |
| `heart_hum` | Shimmering sine chord with vibrato (loop) |
| `collapse_rumble` | Heavy low noise + random impacts (loop) |
| `low_fuel_beat` | Soft heartbeat double-thump |
| `win_jingle` / `lose_sting` | Rising major arpeggio / descending minor tones |
| `ui_click` / `ui_hover` | Tiny blips |

### Materials (`MaterialFactory`)
Stone wall, floor, moss (alpha-clipped), clay, wood, metal (spikes and darts), gem (emissive teal-white), Heart (emissive `#2EE6D6`, high intensity), the 3 key tablets (stone + emissive glyph: sun orange, moon pale blue, serpent green), socket off/on, fire particle (additive orange), ember particle, dust particle, daylight glow (emissive warm white), explorer skin/cloth/hat/leather.

### Explorer character (`ExplorerBuilder`, primitives only)
Hierarchy under `Player` (CharacterController: height 1.8, radius 0.35):
`Model` → Hips → Torso (capsule, khaki) → Head (sphere, skin) → Hat (flat cylinder brim + cylinder crown, brown) · Satchel (box, leather, on a strap) · LeftArm/RightArm (capsules pivoting at the shoulders) · LeftLeg/RightLeg (capsules pivoting at the hips) · **Torch** in the right hand (wood handle + flame ParticleSystem + embers + Point Light).
`ProceduralAnimator`: legs and arms swing with a sine wave scaled by movement speed, a small body bob, the torch arm held raised, an idle "breathing" sway, and a hit flinch.

### Post-processing (`PostFXBuilder`)
- `Global Volume` profile: Bloom (threshold 0.9, intensity 0.8), Vignette 0.35, Color Adjustments (slightly warm), light Film Grain.
- `Collapse Volume` profile: Color Adjustments colour filter red, stronger vignette, chromatic aberration. Starts at weight 0 and lerps to 1 during the collapse.
- Create the `VolumeProfile` with `ScriptableObject.CreateInstance`, add components with `profile.Add<T>()`, save with `AssetDatabase.CreateAsset` + `AddObjectToAsset`. The camera needs `UniversalAdditionalCameraData.renderPostProcessing = true`.

### Darkness settings (Temple scene)
No directional light (or a disabled one). Ambient = flat, very dark blue-black (0.02, 0.02, 0.03). Fog = exponential squared, black, density ≈ 0.05. Camera clear = solid black. The **only** strong lights are the player's torch, the Heart glow, and the daylight behind the exit.

## 7. Gameplay Scripts: behaviour spec

| Script | Behaviour |
|---|---|
| `GameManager` | Singleton per scene. States: `Intro → Playing → Paused → Collapse → Won / Lost`. Holds `Settings`, the difficulty multiplier, and the run timer. Raises events: `OnStateChanged`, `OnGameOver(bool won, string reason)`. |
| `ScoreManager` | Adds points with a reason, tracks a breakdown (gems, oil, keys, heart, penalties, bonuses), raises `OnScoreChanged`. |
| `PlayerController` | Camera-relative WASD/arrows, Shift = sprint, gravity, smooth rotation toward the move direction, footstep sounds per stride. Disabled outside Playing/Collapse. |
| `ThirdPersonCamera` | Mouse orbit (yaw + clamped pitch), follows the shoulder offset, SphereCast pulls the camera in front of walls, cursor locked while playing. Works with `CameraShake`. |
| `TorchSystem` | Fuel drains per second (× sprint multiplier × difficulty multiplier). Light range lerps min→max by fuel %. Perlin flicker on intensity. Flame particle size scales with fuel. Below the warning %: HUD pulses + heartbeat sound. At 0: lose, reason *"The darkness took you."* `Refuel(amount)`. |
| `PlayerHealth` | Hearts, `TakeDamage(1, sourcePos)`, knockback, invincibility frames with a model blink, red screen flash, score penalty. At 0 hearts: lose, *"The temple claimed another explorer."* |
| `Inventory` | Booleans hasSun / hasMoon / hasSerpent / hasHeart. Event for the HUD key icons. |
| `Collectible` | Type enum: Gem / Oil / Key(Sun/Moon/Serpent) / Heart. Bobs + rotates, trigger pickup → effect, sound, score, floating "+10" text, small particle burst. |
| `KeyDoor` | Needs a key type. Within 3 m: if the player has the key, the door slides down into the floor over 1.5 s (grind sound + small shake); if not, HUD hint *"Sealed. Needs the Sun Key."* |
| `SanctumDoor` | 3 sockets. Press **E** within 3 m: places every key the player has (socket lights up + chime). When all 3 are placed it opens. Otherwise the hint shows the missing keys. |
| `EntranceDoor` | Open at start, slams shut 1.5 s after the Intro ends (slam sound + big camera shake + dust). |
| `HeartOfEternity` | Floating crystal with a teal point light and a hum. Pickup → +200, `CollapseSequence.Begin()`. |
| `CollapseSequence` | Countdown (`collapseDuration`) on the HUD, collapse volume weight → 1, continuous light camera shake, rumble loop, `FallingDebris` rocks spawn near the player (a hit = 1 damage, with a red warning circle on the floor 0.8 s before). Opens `ExitGate`. At 0: lose, *"The temple sealed itself forever."* |
| `ExitGate` | Sealed slab. Opens (rises) when the collapse begins. A trigger beyond it = WIN. White fade-out. |
| `SpikeTrap` | Cycle: down → warn (spikes poke up a little + click) → up (damage on contact) → down. Phase offset from tile position for a wave pattern. |
| `DartTrap` | A pressure plate sinks when stepped on. After 0.25 s, darts fire from both side walls across the tile. Cooldown. Darts damage on hit and are destroyed on wall contact. |
| `BoulderTrap` | Stepping on the `b` tile releases the boulder at `B`. It rolls along the lane (rotating visually) at `boulderSpeed` with a rumble, damages + knocks back on hit, and shatters into debris at the end wall. One-shot. |
| `AudioManager` | Pooled one-shot SFX, music/ambience loops, master + SFX volume from settings (saved in PlayerPrefs). |
| `CameraShake` | `Shake(intensity, duration)` using Perlin offsets, plus a "continuous" mode for the collapse. |

**Controls:** WASD / Arrows = move · Mouse = look · Shift = sprint (burns more fuel) · E = interact · Esc = pause

## 11. Troubleshooting notes for Claude Code
- **Pink materials** → the material wasn't created with a URP shader, or the shader got stripped. Recreate it via `MaterialFactory`.
- **Everything too dark to play** → raise the torch `maxLightRange`/`lightIntensity` or the ambient slightly. Don't add other lights.
- **Input not working** → check `activeInputHandler` and the `InputSystemUIInputModule` on the EventSystem.
- **UI not clickable after the game ends** → unlock the cursor (`Cursor.lockState = None; Cursor.visible = true`) and reset `Time.timeScale = 1` when loading scenes.
- **Camera inside walls** → the SphereCast radius is too small, or the wall layer is missing from the camera collision mask.
- **Build works in the editor but not the exe** → probably `Resources` loading or `Shader.Find`. Load the maze through `Resources.Load<TextAsset>("maze")`.
