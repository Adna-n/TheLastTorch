# The Last Torch: rules for Claude Code

Unity **6000.3.24f1**, URP (Universal 3D), Windows build. Third-person temple-maze escape.
The full spec is in `THE_LAST_TORCH_PLAN.md` (read it before working). The level layout is `maze.txt`.

## Workflow
- Work **one phase at a time** (plan section 9). After each phase: list the files created, give exact
  Unity click steps to test, commit to git, then **stop and wait** for the user.
- Every asset (textures, meshes, materials, audio, prefabs, scenes, UI) is **generated by C# editor
  scripts**. No external asset packs.
- Every script starts with a 2–4 line comment explaining what it does (the user explains it to an instructor).

## Code rules
- Namespaces: `LastTorch` (runtime), `LastTorch.EditorTools` (editor, under `Assets/Scripts/Editor/`).
- **Input:** new Input System only (`activeInputHandler: 1`). Poll `Keyboard.current` / `Mouse.current`.
  Never use `Input.GetAxis`. EventSystem uses `InputSystemUIInputModule`.
- **UI:** uGUI + legacy `UnityEngine.UI.Text` with `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")`.
  No TextMeshPro. Canvas Scaler: Scale With Screen Size 1920×1080, match 0.5. UI is built by code.
- **Shaders:** never `Shader.Find` at runtime. Materials are `.mat` assets made in the editor with
  `Universal Render Pipeline/Lit`, `/Unlit` or `/Particles/Unlit`. Emission: `EnableKeyword("_EMISSION")`,
  `_EmissionColor`, `globalIlluminationFlags = RealtimeEmissive`.
- Generated assets are saved as assets: meshes `.asset`, textures PNG + `TextureImporter`, audio `.wav`,
  materials `.mat`, prefabs via `PrefabUtility.SaveAsPrefabAsset`.
- Generators are **deterministic** (fixed seed) and **idempotent** (re-running overwrites cleanly).
- **Tunables** live only in `GameSettings` (`Assets/Settings/GameSettings.asset`), accessed via
  `GameManager.Settings`. No magic numbers in gameplay scripts.
- Remove colliders from decorative primitive parts.
- Maze is loaded with `Resources.Load<TextAsset>("maze")` from `Assets/Resources/maze.txt`.
- Scenes: `Assets/Scenes/MainMenu.unity` (build index 0) and `Assets/Scenes/Temple.unity`.

## Editor menu: "The Last Torch"
`1. Generate Assets` · `2. Build Scenes` · `Build All (1 + 2)` · `3. Build Windows EXE` · `Reset Saved Profiles`.
`LastTorch.EditorTools.ProjectBuilder.BuildAllBatch()` is the command-line entry point.

## Compile check (only when Unity is closed)
```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.3.24f1\Editor\Unity.exe" -batchmode -nographics -quit `
  -projectPath "$PWD" -executeMethod LastTorch.EditorTools.ProjectBuilder.BuildAllBatch -logFile Logs/batch.log
Select-String -Path Logs/batch.log -Pattern "error CS"
```
Before `ProjectBuilder` exists, drop `-executeMethod ...` to just compile. Batchmode fails if the Editor
has the project open; in that case ask the user to check the Console.
Note: Unity 6000.6.0f1 is also installed. Always use **6000.3.24f1** for this project.
